IMPORTANT LIMITATIONS:
This is a free static starter website. The admin passcode is visible in the source code.
Property data and demo registration records are saved only in the current browser's
localStorage, not on a server and not shared across devices. Clearing browser data can
erase them. The form opens WhatsApp; it does not securely submit data to a database.
For a real multi-user admin dashboard and customer registration system, add secure
authentication and a hosted database/backend (for example, Supabase or Firebase).
Replace the sample listings with verified property details before publishing.
Do not collect OTPs, bank passwords, or sensitive identity/financial information.
Free hosting options include GitHub Pages and Netlify. A custom domain generally costs extra.
